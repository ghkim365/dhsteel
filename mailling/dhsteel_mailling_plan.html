💡 에이전트 의견 및 권장 방향

대표님의 의견대로 "별도의 이력 관리(로그) 시트를 생성하여 데이터를 누적하는 것"이 아웃바운드 영업 관리 측면에서 가장 훌륭한 접근입니다.
O열(발송일) 하나의 셀에 데이터를 계속 줄바꿈 등으로 우겨넣으면 나중에 특정 업체가 "몇 번을 받았는지", "마지막으로 언제 발송했는지" 통계를 내거나 분석하기가 매우 어려워집니다.
따라서 메일이 발송될 때마다 별도의 mail_log 시트에 한 행(Row)씩 기록을 쌓고, 메인 company 시트에서는 수식(VLOOKUP, MAXIFS, COUNTIF)을 활용하여 실시간으로 최종 발송일과 발송 횟수, 경과일수를 자동으로 계산해 보여주는 하이브리드 설계 방식을 제안합니다.

📊 1. 스프레드시트 구조 설계

[메인 시트: company] 구조 변경 및 수식 적용

열 번호 (예시) 컬럼명 설명 / 역할 적용할 수식 또는 제어 방식
M열 발송대기 (회차) 현재 회차 발송 대상 여부 (예: 1일차, 9일차 등) 직접 입력 혹은 스케줄러 자동 입력
N열 발송상태 메일 발송 작업 진행 상태 GAS가 발송 후 "발송완료" 또는 "실패"로 기록
O열 최종 발송일 해당 업체에 마지막으로 메일을 발송한 날짜 =IFERROR(MAXIFS(mail_log!A:A, mail_log!B:B, B2), "")
(회사명 기준 가장 최근 로그 날짜 매칭)
P열 발송경과 최종 발송일로부터 오늘까지 지난 일수 =IF(ISBLANK(O2), "", TODAY() - O2)
Q열 누적 발송 횟수 지금까지 총 몇 번 메일을 발송했는지 카운트 =COUNTIF(mail_log!B:B, B2)
🎨 셀 색상 강조 자동화 (조건부 서식 설정 규칙)
10일차 도래 시 눈에 띄게 셀 색상을 변경할 수 있도록 다음과 같이 조건부 서식을 지정합니다.
규칙: P열 >= 10 인 경우 셀 배경색을 연한 빨간색/오렌지색 계열로 채우기 적용.

⚙️ 2. Google Apps Script (GAS) 수정 계획

기존 google_apps_script_outbound.js 파일의 발송 로직을 보완하여 로그 시트에 데이터를 누적 기록하도록 개선합니다.

// [GAS 추가 예정인 로그 작성 함수 예시] function writeMailLog(companyName, email, round, status, detail) { var ss = SpreadsheetApp.getActiveSpreadsheet(); var logSheet = ss.getSheetByName("mail_log"); // 만약 mail_log 시트가 없으면 자동 생성 if (!logSheet) { logSheet = ss.insertSheet("mail_log"); logSheet.appendRow(["발송일자", "회사명", "이메일", "발송회차", "발송상태", "세부결과"]); logSheet.getRange("A1:F1").setFontWeight("bold").setBackground("#f1f5f9"); } var today = new Date(); logSheet.appendRow([today, companyName, email, round, status, detail]); }

메일 발송 함수(sendOutboundEmails)가 실행될 때, 각 행마다 발송이 성공하면 위의 writeMailLog를 호출하여 이력을 누적시킵니다.
