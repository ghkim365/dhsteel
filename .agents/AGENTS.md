# Agent Rules — 대흥정밀 프로젝트 (AGENTS.md)

## 📌 작업 전 견적 승인 규칙 (필수)

모든 코드 변경, 파일 생성/삭제, 대규모 검색 작업을 시작하기 전에 **반드시** 아래 형식으로 작업 견적을 제시하고,
사용자의 명시적 승인(예: "그래", "진행해", "OK" 등)을 받은 후에만 실행한다.

### 즉시 실행 가능한 예외 (견적 불필요)
- 파일/코드 내용 조회 (읽기 전용)
- 짧은 설명·답변 제공
- 1줄 이내의 단순 오탈자/포맷 수정

### 견적 제시 형식

```
### 🔍 작업 견적

| 항목 | 내용 |
|------|------|
| **작업 내용** | (무엇을 할 것인지 한 줄 요약) |
| **예상 토큰 사용량** | ~X,XXX 토큰 (Input: ~XXX / Output: ~XXX) |
| **예상 소요 시간** | 약 X분 |
| **수정/생성 대상 파일** | `파일명1`, `파일명2` |
| **영향 범위** | 기존 기능에 미치는 영향 여부 |

✅ 진행하시겠습니까?
```

사용자가 승인하면 작업을 진행하고, 거절하거나 수정 요청 시 견적을 다시 제시한다.
