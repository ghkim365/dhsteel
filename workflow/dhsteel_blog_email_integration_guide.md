# ✉️ 대흥정밀 B2B 인프라 운영 가이드
## - 이메일 발신/수신 이원화 및 네이버 블로그 안전 발행 전략 -

본 문서는 대흥정밀 B2B 영업 마케팅 인프라(이메일 문의 연동 및 네이버 블로그 포스팅)의 보안 이슈를 우회하고 마케팅 효과를 극대화하기 위해 실무 담당자가 준수해야 할 운영 전략을 설명합니다.

---

## 1. B2B 견적 메일 연동: 발송/수신 이원화 (Dual-Email Strategy)

### 🔴 기존 방식의 문제점 (네이버 메일 외부 연동 한계)
* 대흥정밀 공식 메일 주소인 `daeheungsteel@naver.com`은 네이버 보안 정책(2단계 기기 인증, 로그인 제한 등)으로 인해 외부 프로그램(SMTP)을 통한 자동 알림 발송이 도중에 예기치 않게 끊기는 문제가 자주 발생합니다.

### 🟢 해결책: Gmail 발송 + 네이버 수신 이원화 적용
* **수신(Inbox) - 기존 유지**: 네이버 광고, 웹사이트, 블로그 등 기존 모든 채널에 노출되는 대외 연락처는 기존 그대로 **`daeheungsteel@naver.com`**을 사용합니다.
* **발송(SMTP/API) - 지메일 변경**: 구글 광고 운영용으로 등록된 **회사 구글 계정(Gmail)**을 발송 전용 엔진으로 설정합니다.
* **동작 프로세스**:
  1. 고객이 모바일 카탈로그에서 B2B 파이프 가공 견적을 요청합니다.
  2. 시스템이 구글 광고 계정의 지메일을 사용하여 발송 요청을 보냅니다.
  3. 담당자 대표 메일인 `daeheungsteel@naver.com`으로 실시간 견적 접수 알림이 즉시 수신됩니다.

### 🎯 이원화 도입에 따른 기대 효과
1. **보안 설정 간소화**: 실무 담당자가 네이버의 까다로운 2단계 인증이나 차단 경고를 신경 쓸 필요가 없습니다.
2. **전송 성공률 극대화**: 구글의 신뢰도 높은 이메일 발송 서버를 경유하므로, 견적 문의가 누락되지 않고 안전하게 전송됩니다.
3. **기존 광고 유지**: 홈페이지, 명함, 블로그 등에 표기된 이메일 주소를 변경하지 않아도 됩니다.

## 2. 네이버 블로그 포스팅: 수동 복사-붙여넣기 권장 가이드

### ❌ 자동 포스팅 프로그램(매크로)을 사용하면 안 되는 이유
자동 포스팅 프로그램은 네이버의 어뷰징 방지 필터링으로 인해 다음과 같은 치명적인 위험이 따릅니다.

1. **블로그 저품질(Search Penalty) 지정 (최대 리스크)**
   - 네이버 검색 랭킹 AI는 API 또는 가상 자동화 툴로 작성된 글의 입력 속도 패턴을 감지하여 스팸으로 분류합니다.
   - 저품질 블로그로 낙인찍히면 네이버 통합 검색(VIEW 탭, 스마트블록)에서 모든 글이 제외되어 마케팅 노출 효과가 완전히 상실됩니다.
2. **보안 로그인(CAPTCHA) 상시 발생**
   - 크롤러나 봇으로 간주되면 영어/숫자 보안 문자 입력 창이 나타나므로 로그인 단계에서 자동화가 멈추게 됩니다.
3. **공식 API 폐쇄**
   - 네이버는 2020년 5월부로 개인 블로그 대상 외부 글쓰기 API 서비스를 완전히 종료했습니다.

### 💡 가장 안전하고 확실한 솔루션: "1분 수동 포스팅"
저희가 구현해 드린 **블로그 미리보기 시안 페이지**를 사용해 직접 등록하는 것을 권장합니다.

* **발행 절차 (1분 소요)**:
  1. 관리자 대시보드 상단 메뉴에서 `✍️ 공식 블로그 시안`을 클릭하여 엽니다. (비밀번호 입력 자동 우회 적용 완료)
  2. 본문 영역의 글을 복사(Ctrl + C)하여 네이버 블로그 글쓰기 창에 붙여넣습니다(Ctrl + V).
  3. 시안 파일의 이미지들을 각각 저장하여 본문에 수동으로 업로드합니다.
  4. '발행' 버튼을 클릭하면 완료됩니다.
